## 5. 已知限制（写进交付，不隐瞒）

- 迁移暂不支持跨 `.minecraft` 目录（同目录内多实例可用；跨目录是 V2）。
- 自更新替换失败会回滚但保留 `%TEMP%` 下的备份目录（便于排查），不自动重试。
- 下载器无 Range 断点续传（V1 明确不做），卡死 60s 会切换镜像。
- 更新/安装的真实 Release 成功路径要等 6.0；当前最新 5.5 被有意拦截。
- 网络：GitHub 未认证 API 60 次/小时，产品用缓存 + 可选 `RSTC_GITHUB_TOKEN` 兜底。
- 仓库未推送到 GitHub（本地 master 领先远端），推送需用户确认。

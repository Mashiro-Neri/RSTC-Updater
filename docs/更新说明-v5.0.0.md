# 红石镇客户端更新器 v5.0.0

这是 v5 更新器的首个正式版。安装包不包含 PCL/，PCL2 与 HMCL 均可使用。

## 下载
- `RSTC-Updater-5.0.0.zip`（1.86 MiB）
- SHA256：`CFB410566693E40DF5F6D7AAF93C881854FDB864342F6628FBDDC1F1C0747613`

## 使用
1. 解压后双击 `启动.bat`（或 `RstcUpdater.exe`）；
2. 菜单 `↑↓` 移动、`Enter` 确认、`Esc`/`Ctrl+C` 退出；
3. 「安装到新目录」按向导走：选择游戏目录（可直接用 Windows 文件夹选择器）→ 实例名 → 整合包来源 → 下载方式 → 确认；
4. 安装完成后在 PCL2/HMCL 里选择「红石镇客户端」实例启动。

## 主要变化
- v4 风格的红框 + 像素 RST 终端界面，方向键操作；
- 安装向导 5 步、每步可返回；提供 Windows 原生文件夹 / zip 选择器；
- 下载：原版 MC 自动 BMCLAPI 镜像加速（失败自动回退官方）、整合包自动测速选择镜像、支持 HTTP 代理；
- 原版与整合包并行下载，进度条同屏显示；
- 安装后自动清理多出来的 `fabric-loader-*` 版本项，启动器里只保留客户端实例与原版 26.3；
- 整合包 sha256 强校验、安装后 `INSTALL_VERIFY=PASS`。

## 重要说明
- **6.0 整合包目前是内测（Beta）版本**：稳定版 5.5 基于 MC 1.21.10，与 26.3 不兼容；更新器会自动选择兼容的 Beta 6.0。6.0 正式版发布后会自动改走稳定版，无需更新更新器。
- **v4 老更新器不会自动升级到 v5**（v4 自更新只认自己的脚本资产）：请手动下载本 zip，解压替换旧更新器目录。
- 本程序暂未签名，Windows SmartScreen 提示时请核对上面的 SHA256 后选择“仍要运行”。
- 建议控制台窗口宽度 ≥80 列；下载中 `Ctrl+C` 可中断，重跑会复用已下载文件。
- 自更新：发布后的**下一版本**可完整验证 E1/E2；本版本 `--check-self` 只确认「已是最新」。

## 已知限制
- 迁移暂不支持跨 `.minecraft` 目录（V2）；
- 自更新替换失败会回滚但保留 `%TEMP%` 备份目录，不自动重试。
